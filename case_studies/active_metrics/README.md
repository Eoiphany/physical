# Active metrics snapshot

This snapshot includes RadioMapSeer, UrbanRadio3D, USC, and the provisional
PPData5D geometry case. Boston and UCLA are excluded by study decision. The
three signed-dB rows were recomputed from completed raw arrays using the
building-interior evaluation rule; raw solver maps remain unchanged. PPData5D
has no signed-dB row because its Tx metadata and RSS-to-dB calibration are not
verified in the inspected files.
