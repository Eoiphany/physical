# rebuilt_20261006_1

This case-study batch uses the signed physics-prior convention in the repository:

- open LOS pixels: `P_prior = FSPL` exactly;
- NLoS pixels: `P_prior = FSPL + L_diff`, with `L_diff` supplied by the selected deterministic CD/RD method;
- building pixels in the displayed/evaluation map: the minimum finite signed GT label found on the current Tx's building pixels. This is a rendering/evaluation rule; raw solver arrays are preserved.

The generated local outputs are under `runs/cross_dataset_physics_prior/rebuilt_20261006_1/` and intentionally exclude PPData5D.

Dataset bodies remain external. Re-run from the repository root by replacing the placeholder data roots:

```powershell
\.venv\Scripts\python.exe run_physics_prior.py `
  --data-root <DATA_ROOT> `
  --config configs\boston.json `
  --scene-ids 1 --tx-ids 0 `
  --diffraction-mode auto `
  --output-dir runs\cross_dataset_physics_prior\rebuilt_20261006_1\boston\scene1_tx0
```

The two dense RadioMap cases additionally have `metrics/` generated by
`visualize_physics_prior_metrics.py`. Their metric normalization range remains
the configured fixed range; only the building display floor is GT-derived per
sample.
